Browser Workbench __VERSION__ · 安装说明

1. 安装
   把“Browser Workbench”拖到旁边的“应用程序”文件夹，然后在“应用程序”里双击打开。

2. 第一次打开时，macOS 可能拦截
   当前版本没有使用付费的 Apple 开发者证书签名，macOS 会提示无法验证或已阻止打开。处理一次即可：
   打开“系统设置 → 隐私与安全性”，在页面下方找到“Browser Workbench”，点“仍要打开”，再按提示输入电脑密码。

3. Docker
   浏览器环境运行在 Docker 里，应用会自动检查：
   · 还没安装 Docker Desktop：按应用里的步骤下载、安装并打开一次，回到应用后会自动继续。
   · 已经安装：应用会自动打开 Docker，并载入自带的浏览器组件（只需一次，几分钟内完成，不用联网下载）。
   Docker Desktop 自己的服务条款、首次启动提示需要你在 Docker 窗口里完成。

4. 开始使用
   在“订阅与线路”里粘贴订阅链接，然后新建环境、打开浏览器。
   关闭窗口不会停止环境；退出应用时，如果还有环境在运行，会询问是否一起停止。

数据和日志
   数据：~/Library/Application Support/BrowserWorkbench（订阅、登录数据，请勿分享）
   日志：~/Library/Logs/BrowserWorkbench
   用过旧版（网页版）工作台：菜单“文件 → 导入旧版工作台数据…”，选择旧版目录里的 data 文件夹。只复制，不改动旧数据。

卸载
   退出应用，把“Browser Workbench”移到废纸篓。需要连数据一起删除时，再删除上面的数据文件夹。
   浏览器组件镜像留在 Docker 里，可在 Docker Desktop 的 Images 中删除 local-browser-workbench。
